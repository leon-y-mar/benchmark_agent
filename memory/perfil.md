# Perfil · Cómo hago benchmark

Lo leen `benchmarker` y `analista` antes de cada ronda. Se llena con
`/calibrar` (entrevista + benchmarks reales tuyos) y con learnings aprobados.
**Solo el humano aprueba cambios.** Campo vacío = el agente usa su default y lo
declara.

Formato de cada respuesta: texto + `· origen: <entrevista fecha | tarea/ronda>`

## 1. Antes de buscar
- ¿Qué pregunta te haces antes de abrir Mobbin?
- ¿Partes del flujo completo o de un momento crítico?
- ¿Cuántas referencias consideras suficientes?

## 2. Dónde buscas
- ¿Solo competencia directa, o también industrias análogas? ¿Cuáles?
- ¿Qué apps o mercados son obligatorios? ¿Cuáles evitas y por qué?
- ¿Qué fuentes usas además de Mobbin (capturas propias, apps locales, Baymard)?

## 3. Cómo seleccionas
- ¿Qué hace que una referencia sea **top** para ti?
- ¿Qué te hace descartar una referencia aunque se vea bien?
- ¿Prefieres pantallas sueltas o flujos completos?

## 4. Cómo lo presentas en Figma
- ¿Agrupas por momento del flujo, por patrón o por app?
- ¿Qué anotas al lado de cada referencia?
- ¿Cómo se ve un insight bueno? (pega un ejemplo tuyo)

## 5. Para quién
- ¿Quién consume el benchmark (tú, equipo, stakeholders) y qué decisión toman con él?
